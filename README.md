# akshat@portfolio

Terminal-styled personal site. Next.js App Router + JetBrains Mono, no UI framework —
styling is inline styles plus `app/globals.css`. Deploys to Cloudflare Workers via OpenNext.

```bash
npm run dev      # local dev
npm run deploy   # build + ship to Cloudflare
```

Set `GITHUB_USERNAME` to point the contribution graph at a different account
(defaults to `jainakshat30`).
